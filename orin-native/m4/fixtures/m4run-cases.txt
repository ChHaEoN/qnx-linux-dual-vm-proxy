# m4run: synthetic
# Run-level cases for parse-m4.py selftest (m4-design.md 14.19, I35). Each case builds a SYNTHETIC
# board r1 record from m4fix-1.txt with synth-com3's board profile, applies its edits, runs `run`
# on it and compares the parse log. They cover the wiring the helper cases (I31) cannot reach: a
# rule that is written, but never read by its criterion, fails here. A test input, not a record,
# with no measured figure.
#
# Grammar, one directive per line; blank lines and # lines are ignored:
#   case NAME                     starts a case
#   sub OLD => NEW                replace OLD in every console line holding it, on COM3 and the black box
#   sub-com3 OLD => NEW           the same, on COM3 only
#   resub REGEX => REPL           re.sub on every console line, both records
#   del PREFIX                    delete every console line whose text, left-stripped, starts with PREFIX
#   del-first PREFIX, del-last PREFIX   delete only the first or the last such line
#   add-after LINE => NEW         insert NEW after the first console line equal to LINE
#   vbody-del TEXT                drop every listing line holding TEXT from block v, before it is hashed
#   param KEY=VALUE               set a params key
#   arg KEY=VALUE                 a run option: blackbox_board_sha256=auto|none|<hex>, reset_reason=TEXT
#   expect KEY=VALUE              that parse-log line, exactly
#   expect KEY~TEXT               that parse-log line holds TEXT (a crit_ line must also read fail)
# Every edit must change at least one line, or the case is itself a failure. Every crit_ line a case
# names no expectation for must read pass or n/a.

case clean
expect run_verdict=pass
expect records_stamp_ipc=identical
expect blackbox_board_sha256=equal
expect xcheck_pairs~pc_in_range=
expect xcheck_pairs~c_in_range=
