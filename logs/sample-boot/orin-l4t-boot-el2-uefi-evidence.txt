# Curated evidence -- the Orin Nano's OWN boot record for the claims in docs/orin-port.md and ADR-003
# (captured 2026-09-09 over ssh, read-only: dmesg, /proc/device-tree, /sys/firmware). Previously the
# repo asserted "UEFI hands off at EL2 / VHE" for this board from a public AGX Orin dmesg -- a
# test-before-claim gap the ADR-003 research flagged. This is the board itself. Hostname/IP redacted.
#
# What it shows: EDK II UEFI (EFI v2.70), PSCI 1.1 via SMC, every CPU entered at EL2, ACPI interpreter
# DISABLED (device-tree boot; /sys/firmware/acpi/tables absent), /sys/firmware/efi present, machine
# model "Orin Nano ... Developer Kit Super", Tegra234 compatible string. KVM lines are included for the
# GICv3 story: note "GICv3: no GICV resource entry" and "disabling GICv2 emulation".
# ---------------------------------------------------------------------------
